Insulin Dose Calculator v8

Changes from v7
- Removed the visible "Negative correction reduces meal dose" setting.
- Negative corrections now automatically reduce the meal bolus when applicable.
- Recent bolus / active insulin is collapsed by default.
- Breakdown is collapsed by default.
- Basal self-titration is collapsed by default.
- Each of those sections opens by tapping its heading and closes by tapping the
  heading again.
- TDD tools remain collapsed.
- Exponential active-insulin model and all other v7 calculations are preserved.
